# 經典圖論問題

## 一、 霍夫曼編碼(Huffman Code)

假設編碼系統有A, B,C, D, E, F 等六個符號，期出現頻率依序為0.2, 0.15, 0.3,
0.18, 0.05,0.12，試設計霍夫曼碼？

![霍夫曼樹](/img/fig_a4-6-1.png){width=60%}

**編碼結果**

A: 01　B:110　C:10　D:00　E:1110　F:1111

解碼時由霍夫曼樹根開始，根據 "0" 或,"1" 來決定往左子樹或右子樹搜尋，到
達樹葉時掃可解出該字母。然後再重新由樹根，重覆同樣程序解出次一字母，餘此類
推。

**練習：**
100111111110 表示什麼字 (　　　)

## 二、 尤拉路徑(一筆劃問題)

Königsberger 七座橋問題 

在十八世紀時東普魯士科尼格斯堡，被普列戈利亞河 (Pregolya River)分成四個區域。共有七座橋連接這些區域，如下圖所示。

![圖一 七座橋問題](/img/fig_a4-6-2.png){width=80%}

下圖則為圖一的簡化圖

![圖二](/img/fig_a4-6-3.png){width=40%}

七座橋問題是「`在所有橋都只能走一遍的前提下，如何才能把所有的橋都走遍？`」  
- 尤拉路徑(Euler Path)：從某一頂點出發，經過圖中每一個邊，而且只能通過一次
- 尤拉迴路(Euler Circuit) ：上述路徑的起點和終點為同一點  
- Koenigsberg 七座橋不可能有 Euler Circuit 

### 簡單敘述定理

G = graph ；V = vertex ；E = edge ；
degree：附於該點之邊數（$\deg^+$ 為入度數 in_degree；$\deg^-$ 為出度數 out_degree）

::: info 無向圖 — 尤拉路徑
設 G=(V,E)為一無向圖，G 有尤拉路徑的充要條件是：
G 具有連通性而且恰有兩頂點的 degree 為奇數，其餘各頂點的 degree 皆為偶數。
:::

::: info 無向圖 — 尤拉迴路
設 G=(V,E)為一無向圖，G 有尤拉迴路的充要條件是：
G 具有連通性而且所有的頂點 degree 均為偶數。
:::

::: info 有向圖 — 尤拉路徑
設 G=(V,E)為一有向圖，G 有(有向)尤拉路徑的充要條件為：
G 具有連通性而且恰有兩頂點(分別用 u 和 v 表之)使得

$\deg^+(u)=\deg^-(u)+1$　　及　　$\deg^-(v)=\deg^+(v)+1$；

而且其他各頂點 w，必須滿足

$\deg^+(w)=\deg^-(w)$
:::

::: info 有向圖 — 尤拉迴路
設 G=(V,E)為一有向圖，G 中存在有向尤拉迴路的充要條件是
G 具有連通性而且所有頂點的進次數和出次數相等。
:::

## 三、 漢米頓路徑(旅行銷售員問題)

1. 漢米頓路徑 – 每個點經過一次
2. 漢米頓迴路 – 每個點經過一次，最後回到原點

NP-complete（NP 非確定性多項式時間，Non-deterministic Polynomial time）

- ✓ 沒有已知的多項式時間解法（目前全世界都找不到）
- ✓ 但它可以在多項式時間內驗證解答
- ✓ 如果有人找到一個快速解法，就等於整個 NP 類問題都能快速解
