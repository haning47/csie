# 最小生成樹 (Minimum Spanning Tree, MST)

在圖論中，**最小生成樹 (Minimum Spanning Tree, MST)** 是指一個無向連通圖中，連結所有頂點且邊權重總和最小的樹狀子圖。

---

## 1. Prim 演算法 (點導向)

Prim 演算法的核心思想是「**從點擴展**」，每次在已知集合與未知集合的交界處，挑選權重最小的邊。

### 核心步驟
1. 開始時設定 $U = \{1\}$ (將頂點 1 加入已知集合)。
2. 每一步驟都找一個最小邊 $(u, v)$，其中 $u \in U, v \in V - U$ (一端在已知集合內，一端在未知集合外)。
3. 把 $v$ 加入 $U$ 中。
4. 重覆步驟 2-3 直到 $U = V$ (所有頂點皆被納入)。

### 範例圖解歷程
以下依據範例圖形的執行順序紀錄（起始點為 1）：

* **(1) 選擇邊 (1, 2)**：權重為 1。此時 $U = \{1, 2\}$。
* **(2) 選擇邊 (1, 4)**：權重為 2。此時 $U = \{1, 2, 4\}$。
* **(3) 選擇邊 (4, 7)**：權重為 1。此時 $U = \{1, 2, 4, 7\}$。
* **(4) 選擇邊 (2, 5)**：權重為 3。此時 $U = \{1, 2, 4, 5, 7\}$。
* **(5) 選擇邊 (3, 4)**：權重為 4。此時 $U = \{1, 2, 3, 4, 5, 7\}$。
* **(6) 選擇邊 (3, 6)**：權重為 2。此時所有頂點皆已連通，$U = V$。

## 2. Kruskal 演算法 (邊導向)

Kruskal 演算法的核心思想是「**從邊出發**」，每次挑選全圖中權重最小的邊，只要不形成環（迴路）就納入集合。

### 核心步驟
1. 設定一個邊的集合 $V_{mst}$，一開始為空集合。*(註：為避免與頂點集合 $V$ 混淆，教材內文改寫為 $V_{mst}$)*。
2. 將所有的邊依成本（權重）由小到大排序。
3. 選擇一個最小成本之邊，檢查其和集合 $V_{mst}$ 內之邊是否會構成迴路（迴圈）。若否，則將該邊加入集合 $V_{mst}$ 中。
4. 重覆上述步驟直到所有邊均檢查完畢（或已選滿 $V-1$ 條邊）。

### 範例圖解歷程
將圖中所有的邊依權重排序後，依序檢查：

* **(1) 選擇邊 (1, 2)**：權重 1 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2)\}$。
* **(2) 選擇邊 (4, 7)**：權重 1 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2), (4,7)\}$。
* **(3) 選擇邊 (3, 6)**：權重 2 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2), (4,7), (3,6)\}$。
* **(4) 選擇邊 (1, 4)**：權重 2 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2), (4,7), (3,6), (1,4)\}$。
* **(5) 選擇邊 (2, 5)**：權重 3 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2), (4,7), (3,6), (1,4), (2,5)\}$。
* **(6) 選擇邊 (5, 7)**：權重 4 $\Rightarrow$ **不加入**，因為會與已選的邊形成迴路 (4-7-5-2-1-4)。
* **(7) 選擇邊 (3, 4)**：權重 4 $\Rightarrow$ 加入集合，目前 $V_{mst} = \{(1,2), (4,7), (3,6), (1,4), (2,5), (3,4)\}$。

## 3. 程式碼實作 (Python)

這裡提供對應圖片中範例圖形（共 7 個頂點，1 則對應索引 1）的 Python 實作程式碼。

::: code-group

```python [Prim 演算法]
import heapq

def prim_mst(num_vertices, adj_list, start_node=1):
    mst = []
    total_weight = 0
    visited = [False] * (num_vertices + 1)
    
    # 優先權佇列儲存格式: (weight, current_vertex, parent_vertex)
    min_heap = [(0, start_node, -1)]
    
    while min_heap:
        weight, u, parent = heapq.heappop(min_heap)
        
        if visited[u]:
            continue
            
        visited[u] = True
        total_weight += weight
        if parent != -1:
            mst.append((parent, u, weight))
            
        for next_weight, v in adj_list[u]:
            if not visited[v]:
                heapq.heappush(min_heap, (next_weight, v, u))
                
    return mst, total_weight

# 依投影片範例圖形建立鄰接清單 (1-indexed)
graph_adj = {
    1: [(1, 2), (2, 4), (7, 3)],
    2: [(1, 1), (6, 4), (3, 5)],
    3: [(7, 1), (4, 4), (2, 6)],
    4: [(2, 1), (6, 2), (4, 3), (5, 5), (8, 6), (1, 7)],
    5: [(3, 2), (5, 4), (4, 7)],
    6: [(2, 3), (8, 4), (6, 7)],
    7: [(1, 4), (4, 5), (6, 6)]
}

mst, total_weight = prim_mst(7, graph_adj, start_node=1)
print("Prim MST 選擇順序:")
for u, v, w in mst:
    print(f"選擇邊 ({u}, {v}) => 權重: {w}")
print(f"總權重: {total_weight}")
