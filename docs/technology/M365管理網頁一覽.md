# Microsoft 365 管理網頁一覽

> 所有入口網站都用同一個系統管理員帳號登入；同一個瀏覽器登入一次後，切換到其他入口網站通常不必再輸入密碼。
> 各頁面能看到的功能，取決於登入帳號被指派的管理員角色。

## 核心管理

| 名稱 | 網址 | 主要用途 |
|---|---|---|
| Microsoft 365 系統管理中心 | https://admin.microsoft.com （會轉到 https://admin.cloud.microsoft ） | 新增／編輯／刪除使用者、重設密碼、指派授權、管理群組與共用信箱、組織設定、服務健康情況、訊息中心、帳單、使用量報告 |
| Microsoft Entra 系統管理中心 | https://entra.microsoft.com | 使用者與群組身分管理、管理員角色指派、外部身分識別（來賓、外部共同作業設定、自助式註冊）、企業應用程式與應用程式註冊、條件式存取、MFA 與驗證方法、登入與稽核記錄 |
| Azure 入口網站 | https://portal.azure.com | Azure 訂用帳戶與資源（虛擬機器、儲存體、AI 服務等）；Entra 的功能在這裡也找得到 |

## 各服務管理

| 名稱 | 網址 | 主要用途 |
|---|---|---|
| Exchange 系統管理中心 | https://admin.exchange.microsoft.com | 信箱、共用信箱、通訊群組、郵件流程規則、郵件追蹤、連接器、收件者權限 |
| SharePoint 系統管理中心 | https://admin.microsoft.com/sharepoint （會轉到學校專屬的 `租用戶名稱-admin.sharepoint.com`） | 網站清單與建立、網站儲存空間、外部共用政策、已刪除的網站、OneDrive 設定、存取控制 |
| Teams 系統管理中心 | https://admin.teams.microsoft.com | 團隊管理、會議與通話政策、訊息政策、Teams 應用程式管理、來賓與外部存取、裝置 |
| Microsoft 365 Apps 系統管理中心 | https://config.office.com | Office 應用程式部署設定、雲端原則、更新管道 |
| Microsoft School Data Sync | https://sds.microsoft.com | 從校務系統同步學生、教師、班級資料到 Microsoft 365（教育版） |

## 裝置與安全性

| 名稱 | 網址 | 主要用途 |
|---|---|---|
| Microsoft Intune 系統管理中心 | https://intune.microsoft.com | 裝置註冊與管理、設定檔、合規性原則、應用程式派送、Windows 更新管理 |
| Microsoft Defender 入口網站 | https://security.microsoft.com | 安全性警示與事件、威脅分析、電子郵件與共同作業防護（反垃圾郵件、反網路釣魚原則）、隔離郵件、安全分數 |
| Microsoft Purview 入口網站 | https://purview.microsoft.com | 稽核記錄搜尋、資料遺失防護（DLP）、敏感度標籤、保留原則、電子文件探索（eDiscovery） |

## Power Platform

| 名稱 | 網址 | 主要用途 |
|---|---|---|
| Power Platform 系統管理中心 | https://admin.powerplatform.microsoft.com | 環境建立與管理、Dataverse 容量、資料原則（DLP）、分析報告、支援案件 |
| Power Apps | https://make.powerapps.com | 建立與管理應用程式、資料表 |
| Power Automate | https://make.powerautomate.com | 建立與管理自動化流程 |

## 常用輔助工具

| 名稱 | 網址 | 主要用途 |
|---|---|---|
| Microsoft 365 服務狀態（公開） | https://status.cloud.microsoft | 不用登入即可查看 Microsoft 365 是否有大範圍服務中斷 |
| Graph 總管 | https://developer.microsoft.com/graph/graph-explorer | 在網頁上測試 Microsoft Graph API 查詢 |
| 使用者「我的帳戶」 | https://myaccount.microsoft.com | 一般使用者自行管理密碼、驗證方法、登入裝置 |
| 使用者「我的登入」 | https://mysignins.microsoft.com | 一般使用者查看自己的登入記錄與安全性資訊 |
